# API Contract Registry

Store versioned, technology-neutral request, response, event, and error specifications here. Required initial contracts: document registration, extraction result, insight result, search request/result, routing task, review decision, audit event, and connector health.

Each contract must define: version, owner, compatibility policy, required IDs, source anchors, permission context, idempotency behavior, and example redacted payloads. No implementation is included yet.
