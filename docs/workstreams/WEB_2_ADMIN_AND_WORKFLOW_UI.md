# Web-2 - Admin and Workflow UI

Own `apps/admin-console/` and admin-specific shared UI components.

Deliver source configuration screens, taxonomy/routing-rule management, reviewer queues, action assignment/escalation views, feedback triage, audit-history viewer, and role/permission administration surfaces. Build against versioned mocks/contracts.

Do not build connector internals, background processing, retrieval, model logic, or employee portal. Acceptance: an authorized administrator can review uncertainty, trace an output to source and processing version, and manage a routing rule with an audit record.
