# Web-1 - Employee Portal

Own `apps/web-portal/` and shared presentation components in `packages/ui/`.

Deliver role dashboard, document inbox, document reader launch, source-cited summary presentation, search/results/filters, feedback capture, language display controls, and clear confidence/review labels. Build against versioned mocks/contracts.

Do not implement backend extraction, AI behavior, access policy, routing engine, or admin workflows. Acceptance: an authorized employee can find an item, understand what needs action, inspect evidence, and submit feedback without exposing unauthorized data.
